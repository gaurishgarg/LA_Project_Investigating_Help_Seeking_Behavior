1. Decide what is being predicted before fitting

One row is one student practising one skill. We predict after the first k completed classified main problems. The target is 1 if first-response correctness on all later classified problems is below 50%, otherwise 0.

  • Main analysis: k=3. This was the original pitch's planned window, and avoids selecting a new window for its attractive results.
  • RQ1-aligned sensitivity: k=7. RQ1 selected seven using outcome-defined group differences. We label this exploratory; we do not call it the best predictive window.
  • Each cohort needs at least k later classified problems. Thus k=3 and k=7 use different samples and different outcome windows. Their scores cannot establish whether waiting longer improves prediction.
  • Both cohorts condition on future practice continuing. Conclusions apply to these continuing histories, not every new student or student who stops practising.
  • Primary metric: log loss (lower is better). Secondary: AUC, average precision (AP), Brier score, and calibration. No accuracy threshold is chosen.
  • Main comparison: M2 knowledge baseline versus M3 with transitions, chosen in advance. We do not pick a baseline from test scores.
  • A log-loss gain of 0.005 is an illustrative practical threshold, not a literature-established standard. Agree it with the team before interpreting results.

The results are history-weighted: each history gets one vote. Student grouping and resampling account for students having several histories.

2. Reconstruct RQ1's problem labels, without inheriting fitted results

We use actions, rather than the identifier-free normalized tables. A problem's actions are collapsed into one episode using RQ1's grouping keys and label priority. Scaffold subquestions determine the scaffold outcome but are not separate main-problem opportunities.

Important meanings: BOH takes priority over HINT-FIRST. Therefore HINT-FIRST means hint-first without a later bottom-out or scaffold label. Hint count and first-hint count below also retain behaviour hidden by this priority.

any_scaffold records scaffolding that occurred. It does not establish which correctly answered items offered scaffolding. We call this observed scaffold exposure, not an independently verified item-design control. We also retain hint availability from hintTotal, and problem format. Residual item-design confounding remains possible.

RQ1 combines repeated records with the same student/assistment/problem/skill keys even across assignments. We preserve that convention for comparability; changing the episode definition requires coordinating with RQ1/RQ2.

def parse_time(x):
    # The supplied action CSV uses Unix seconds. Avoid interpreting them as nanoseconds.
    numeric = pd.to_numeric(x, errors='coerce')
    if numeric.notna().mean() > .99:
        return pd.to_datetime(numeric, unit='s', utc=True, errors='coerce')
    return pd.to_datetime(x, utc=True, errors='coerce')

3. Make histories and keep the future separate

Each early sequence contributes exactly k−1 adjacent transitions. All seven states stay in this analysis: conditioning the prediction sample on being wrong would exclude students and answer a narrower question.

We also check that the early problems were completed before later problems began. Overlapping histories and histories containing an action whose end precedes its start are excluded and counted, because features must actually be available at prediction time. This may slightly change the RQ1 sample. Unclassified episodes were excluded as in RQ1; the target concerns classified problems, not all originally attempted problems.

No future counts, later-window length, later help use, final correctness rate, or identifiers enter the predictors. Student IDs only define groups. Skill is an allowed predictor.

def make_histories(ep, k, min_total=None):
    rows=[]; overlaps=0; invalid_times=0
    for (user,skill), g in ep.groupby(['userId','skill'],sort=False):
        if len(g) < (min_total or 2*k): continue
        if g.invalid_time_history.any():
            invalid_times += 1
            continue
        e,l = g.iloc[:k],g.iloc[k:]
        prediction_time = e.end_time.max()
        if l.start_time.min() < prediction_time:
            overlaps += 1
            continue
        state_seq = tuple(e.state)
        correct_seq = tuple(e.first_correct.astype(int))
        later_rate = l.first_correct.mean()
        row = dict(userId=user, skill=str(skill), state_seq=state_seq, correct_seq=correct_seq,
                   problems=tuple(e.problemId), prediction_time=prediction_time,
                   outcome_end=l.end_time.max(), later_rate=later_rate,
                   later_struggle=int(later_rate<.5), n_later=len(l),
                   early_correct=sum(correct_seq), early_scaffold_share=e.any_scaffold.mean(),
                   early_hint_available_share=e.hint_total.gt(0).mean(),
                   early_hint_clicks=e.hint_clicks.sum(), early_bottom_clicks=e.bottom_clicks.sum(),
                   early_hint_problems=e.any_hint.sum(), early_first_hint_problems=e.first_hint.sum(),
                   early_actions=e.n_actions.sum(), early_extra_response_attempts=(e.max_attempt-1).clip(lower=0).sum())
        for typ in TYPES: row['type_'+typ] = e.problemType.eq(typ).mean()
        for st in STATES: row['state_'+st] = state_seq.count(st)
        for j,c in enumerate(correct_seq): row[f'correct_position_{j+1}'] = c
        counts=np.zeros(49,dtype=int)
        for a,b in zip(state_seq[:-1],state_seq[1:]): counts[state_index[a]*7+state_index[b]]+=1
        row['transitions']=counts
        # One fixed randomization per history preserves ALL state counts, but destroys actual order.
        r=np.random.default_rng(np.random.SeedSequence([SEED,int(user),k,int(g.iloc[0].episode_row_order)]))
        seq=list(r.permutation(state_seq)); shuffled=np.zeros(49,dtype=int)
        for a,b in zip(seq[:-1],seq[1:]): shuffled[state_index[a]*7+state_index[b]]+=1
        row['shuffled_transitions']=shuffled
        rows.append(row)
    h=pd.DataFrame(rows).reset_index(drop=True)
    assert not h.duplicated(['userId','skill']).any()
    assert h.transitions.map(np.sum).eq(k-1).all()
    assert h.shuffled_transitions.map(np.sum).eq(k-1).all()
    assert h.correct_seq.map(len).eq(k).all()
    assert h.later_struggle.eq(h.later_rate.lt(.5).astype(int)).all()
    h.attrs['exclusions']={'overlapping_histories':overlaps,'invalid_time_histories':invalid_times}
    print(f'k={k}: {len(h):,} histories, {h.userId.nunique():,} students, {h.later_struggle.mean():.1%} struggle; exclusions={h.attrs["exclusions"]}')

4. Fit BKT: what might the student know after the early responses?

BKT tracks a hidden probability of knowing the skill. It has four parameters: initial knowledge L0, learning T, guessing G, and slipping S. For a response, predicted correctness is L*(1−S)+(1−L)*G. After observing correct/incorrect, Bayes' rule updates L; a learning step then updates it again.

Here we fit a no-forgetting, single-skill BKT by likelihood, using only early correctness sequences of training histories. We try three starting points. Bounds keep guess/slip below .45, learning at most .5. These are explicit modeling assumptions, not verified psychological facts.

We fit a pooled model, then skill models where at least 30 training histories exist. A small penalty shrinks skill parameters toward the pooled fit. Sparse/unseen skills use pooled parameters. Failed optimizations are recorded and use the pooled fit; parameter-bound hits are reported. This is a constrained BKT implementation, not pyBKT or reuse of the supplied priors.

We export knowledge after the early responses and predicted correctness on the next opportunity as features for predicting later struggle. BKT itself predicts next-response correctness, which is a different target from later struggle. The feature adaptation makes that distinction explicit.

Show Python code
BKT_BOUNDS=[(.001,.999),(.001,.5),(.001,.45),(.001,.45)] # L0,T,G,S

def bkt_trace(Y, theta):
    Y=np.asarray(Y,dtype=float)
    L0,T,G,S=np.asarray(theta).T
    L=np.full(Y.shape[0],L0) if np.ndim(L0)==0 else L0.copy()
    nll=0.
    for t in range(Y.shape[1]):
        p=np.clip(L*(1-S)+(1-L)*G,1e-9,1-1e-9)
        y=Y[:,t]
        nll-=np.sum(y*np.log(p)+(1-y)*np.log1p(-p))
        posterior=np.where(y==1,L*(1-S)/p,L*S/(1-p))
        L=posterior+(1-posterior)*T
    return nll,L,L*(1-S)+(1-L)*G

def optimize_bkt(Y, center=None):
    Y=np.asarray(Y,dtype=float)
    starts=[[.3,.1,.2,.1],[.6,.03,.15,.15],[.1,.25,.3,.05]]
    if center is not None: starts[0]=list(center)
    def objective(p):
        value=bkt_trace(Y,p)[0]/Y.size
        if center is not None: value += .01*np.sum((p-center)**2)
        return value
    fits=[minimize(objective,x,method='L-BFGS-B',bounds=BKT_BOUNDS,options={'maxiter':200}) for x in starts]
    good=[f for f in fits if f.success and np.isfinite(f.fun)]
    if not good: return None
    return min(good,key=lambda f:f.fun).x

class BKT:
    def fit(self,h):
        self.pooled=optimize_bkt(np.array(h.correct_seq.tolist()))
        if self.pooled is None: raise RuntimeError('Pooled BKT optimization failed; do not report results.')
        self.by_skill={}; self.audit=[]
        for skill,g in h.groupby('skill'):
            fitted=optimize_bkt(np.array(g.correct_seq.tolist()),self.pooled) if len(g)>=MIN_SKILL_HISTORIES else None
            theta=self.pooled if fitted is None else fitted
            self.by_skill[skill]=theta
            hit=any(abs(x-lo)<1e-4 or abs(x-hi)<1e-4 for x,(lo,hi) in zip(theta,BKT_BOUNDS))
            self.audit.append(dict(skill=skill,n_histories=len(g),pooled_fallback=fitted is None,bound_hit=hit,
                                   L0=theta[0],T=theta[1],G=theta[2],S=theta[3]))
        return self
    def transform(self,h):
        pars=np.array([self.by_skill.get(s,self.pooled) for s in h.skill])
        _,known,next_p=bkt_trace(np.array(h.correct_seq.tolist()),pars)
        return np.column_stack([known,next_p])

5. Fit PFA: what do prior successes and failures imply?

PFA uses logit(correct next) = beta_skill + gamma_skill * successes + rho_skill * failures. Each training response is predicted from counts before that response, never including its own correctness in its predictors.

The code fits a regularized, skill-specific logistic PFA using training histories' early opportunities. We do not impose coefficient signs. A pooled successes/failures model handles unseen skills. The final summary uses all k observed early responses to estimate correctness on the next opportunity.

PFA and BKT are refitted inside every training split. Their fitting data is restricted to the early window, making the information budget explicit and conservative. This is not a benchmark for the best possible KT implementation with additional historical training data.

Show Python code
class PFA:
    def design(self,skills,S,F):
        n=len(skills); ix=np.array([self.lookup.get(s,-1) for s in skills]); good=ix>=0
        rr=np.repeat(np.arange(n)[good],3)
        cc=(ix[good,None]*3+np.arange(3)).ravel()
        vv=np.column_stack([np.ones(n)[good],np.asarray(S)[good],np.asarray(F)[good]]).ravel()
        return sparse.csr_matrix((vv,(rr,cc)),shape=(n,3*len(self.lookup))), good
    def fit(self,h):
        self.lookup={s:i for i,s in enumerate(sorted(h.skill.unique()))}
        Y=np.array(h.correct_seq.tolist()); n,k=Y.shape
        S=np.cumsum(Y,axis=1)-Y; F=np.arange(k)[None,:]-S
        skills=np.repeat(h.skill.to_numpy(),k)
        X,_=self.design(skills,S.ravel(),F.ravel())
        self.model=LogisticRegression(C=1.,fit_intercept=False,max_iter=3000,solver='lbfgs').fit(X,Y.ravel())
        self.pooled=LogisticRegression(C=1.,max_iter=3000).fit(np.column_stack([S.ravel(),F.ravel()]),Y.ravel())
        return self
    def transform(self,h):
        S=h.early_correct.to_numpy(); F=h.correct_seq.map(len).to_numpy()-S
        X,good=self.design(h.skill.to_numpy(),S,F)
        p=self.pooled.predict_proba(np.column_stack([S,F]))[:,1]
        if good.any(): p[good]=self.model.predict_proba(X[good])[:,1]
        return p[:,None]

6. Build the baseline ladder

Model What it knows
M0 correctness Early correct count and correctness at each position, skill, problem formats, observed scaffold exposure, hint availability, training-only item easiness
M1 help counts M0 + hint clicks, bottom-out clicks, first-hint problems, hinted problems, extra actions/response attempts, and counts of each state
M1+BKT M1 + BKT summaries
M1+PFA M1 + PFA summary
M2 knowledge M1 + both BKT and PFA; the preselected full baseline
M3 transitions M2 + all 49 adjacent transition counts
M3 shuffled M2 + transitions after one fixed within-history state shuffle; diagnostic only

M0 already captures the order of correctness. M1 captures the amount and type of help. M3 therefore tests whether transitions add information beyond those summaries. We keep all transitions instead of selecting RQ1's significant ones from the full dataset. Correlated predictors are handled by regularized logistic regression; coefficients are not causal effects.

The shuffled model retains the real correctness-position features and other baseline features; only the added transition block is shuffled. It is a rough diagnostic, not a full counterfactual sequence, permutation p-value, or independent confirmatory test.

Item easiness is the smoothed mean first correctness for a problem among training histories' early episodes only. An unseen problem receives the training average. No precomputed RQ1 item easiness is imported.

class FoldFeatures:
    def fit(self,h):
        self.skills=sorted(h.skill.unique())
        records=[(p,y) for row in h.itertuples() for p,y in zip(row.problems,row.correct_seq)]
        items=pd.DataFrame(records,columns=['problem','correct'])
        self.mean=items.correct.mean()
        stats=items.groupby('problem').correct.agg(['sum','count'])
        self.easiness=((stats['sum']+10*self.mean)/(stats['count']+10)).to_dict()
        self.bkt=BKT().fit(h); self.pfa=PFA().fit(h)
        return self
    def transform(self,h):
        k=len(h.iloc[0].correct_seq)
        cols=['early_correct','early_scaffold_share','early_hint_available_share']+['type_'+t for t in TYPES]+[f'correct_position_{j+1}' for j in range(k)]
        num=h[cols].to_numpy(dtype=float)
        easy=np.array([np.mean([self.easiness.get(p,self.mean) for p in probs]) for probs in h.problems])[:,None]
        skill=np.column_stack([h.skill.eq(s).to_numpy(dtype=float) for s in self.skills])
        X0=np.column_stack([num,easy,skill])
        help_cols=['early_hint_clicks','early_bottom_clicks','early_hint_problems','early_first_hint_problems',
                   'early_actions','early_extra_response_attempts']+['state_'+s for s in STATES]
        X1=np.column_stack([X0,h[help_cols].to_numpy(dtype=float)])
        b,p=self.bkt.transform(h),self.pfa.transform(h)
        X2=np.column_stack([X1,b,p])
        blocks={M0:X0,M1:X1,MB:np.column_stack([X1,b]),MP:np.column_stack([X1,p]),M2:X2,
                M3:np.column_stack([X2,np.stack(h.transitions)])}
        if RUN_ORDER_SHUFFLE: blocks[MS]=np.column_stack([X2,np.stack(h.shuffled_transitions)])
        assert all(np.isfinite(x).all() for x in blocks.values())
        return blocks

def classifier(C):
    # Scaling is learned on training data by the pipeline. No oversampling/class balancing:
    # changing prevalence would distort the probability target and calibration.
    return make_pipeline(StandardScaler(),LogisticRegression(C=C,max_iter=3000,solver='lbfgs'))

def grouped_splits(h,n,seed):
    if h.userId.nunique()<n: raise ValueError('Too few independent students for the requested folds.')
    cv=StratifiedGroupKFold(n_splits=n,shuffle=True,random_state=seed)
    splits=list(cv.split(h,h.later_struggle,h.userId))
    for a,b in splits:
        assert set(h.iloc[a].userId).isdisjoint(h.iloc[b].userId)
        if h.iloc[a].later_struggle.nunique()<2 or h.iloc[b].later_struggle.nunique()<2:
            raise ValueError('A fold has one outcome class. Revise the fixed split protocol; do not silently drop it.')
    return splits

7. Tune inside training, evaluate outside it

Think of two doors. The outer door keeps evaluation students out. Inside the training room, the inner door chooses regularization strength. The outer students are used once for evaluation, never for picking a strength or feature.

For each inner split we refit item easiness, BKT, PFA, the scaler, and logistic models. After choosing a strength for each model, we refit using all outer-training histories and predict the outer-test students. Every model uses identical splits and the same training information.

We tune the final struggle predictor; the KT fitting specification is fixed. This is nested grouped validation of the specified pipeline, not a search over every possible BKT/PFA configuration. The fixed k=7 sensitivity still inherits RQ1's prior outcome-informed window choice.

Show Python code
def tune_strengths(train,seed):
    inner=grouped_splits(train,INNER_FOLDS,seed)
    loss={(name,C):[] for name in MODELS for C in C_GRID}
    for a,b in inner:
        ta,tb=train.iloc[a],train.iloc[b]
        ff=FoldFeatures().fit(ta)
        A,B=ff.transform(ta),ff.transform(tb)
        for name in MODELS:
            for C in C_GRID:
                model=classifier(C).fit(A[name],ta.later_struggle)
                prob=model.predict_proba(B[name])[:,1]
                loss[(name,C)].append((len(tb),log_loss(tb.later_struggle,prob,labels=[0,1])))
    def average(name,C):
        v=loss[(name,C)]; return sum(n*l for n,l in v)/sum(n for n,l in v)
    selected={name:min(C_GRID,key=lambda C:(average(name,C),C)) for name in MODELS}
    return selected

def fit_predict(train,test,seed):
    strengths=tune_strengths(train,seed)
    ff=FoldFeatures().fit(train)
    A,B=ff.transform(train),ff.transform(test)
    predictions={}
    for name in MODELS:
        model=classifier(strengths[name]).fit(A[name],train.later_struggle)
        predictions[name]=model.predict_proba(B[name])[:,1]
    return predictions,strengths,pd.DataFrame(ff.bkt.audit)

def nested_predictions(h,k):
    pred=h[['userId','skill','later_struggle','prediction_time','outcome_end']].copy()
    for name in MODELS: pred[name]=np.nan
    pred['fold']=-1
    audits=[]; parameters=[]
    for fold,(a,b) in enumerate(grouped_splits(h,OUTER_FOLDS,SEED),start=1):
        t=time.time()
        p,cs,audit=fit_predict(h.iloc[a],h.iloc[b],SEED+fold)
        for name,values in p.items(): pred.loc[b,name]=values
        pred.loc[b,'fold']=fold
        audit['fold']=fold; audits.append(audit)
        parameters.append({'fold':fold,**cs})
        print(f'k={k}, outer fold {fold}/{OUTER_FOLDS}: {len(a)} train / {len(b)} test histories ({time.time()-t:.1f}s)',flush=True)
    assert pred[MODELS].notna().all().all()
    return pred,pd.DataFrame(parameters),pd.concat(audits,ignore_index=True)

8. A second validation: genuinely later students

Student-grouped cross-validation estimates performance on other students in this historical dataset; it is not a future deployment test. Here a fixed calendar cutoff is the 70th percentile of prediction dates (dates only, no outcomes).

  • Training histories must have all their later outcome observations finished before the cutoff.
  • Test histories start prediction on/after the cutoff and come from students absent from training.
  • Histories in between, and later histories of training students, are excluded from this test.
  • Inner tuning uses grouped splits within this completed historical training set. It does not use future test students.

This strict split can be much smaller. The notebook reports exclusions and refuses to interpret a tiny/one-class time test. No automatic cutoff search tries to find a better result. It is a retrospective forward-time check, not prospective confirmation after earlier full-data exploration.

Label-maturity limitation: "all later observed practice" has no prospectively known end date. This retrospective purge verifies that no included training outcome action occurs after the cutoff, but uses the completed record to identify those histories. A deployment study should define a fixed prediction horizon or an explicit history-closure rule before collecting data. The present split is not proof that these labels could have been declared final in real time.

Show Python code
def temporal_predictions(h,k):
    cutoff=h.prediction_time.quantile(.70)
    train=h[h.outcome_end<cutoff].copy()
    candidate=h[h.prediction_time>=cutoff].copy()
    test=candidate[~candidate.userId.isin(train.userId)].copy()
    audit={'cutoff':str(cutoff),'train_histories':len(train),'test_histories':len(test),
           'train_students':train.userId.nunique(),'test_students':test.userId.nunique(),
           'future_histories_excluded_shared_student':len(candidate)-len(test),
           'histories_excluded_total':len(h)-len(train)-len(test)}
    print('Temporal audit:',audit,flush=True)
    enough=(len(train)>=200 and len(test)>=100 and train.userId.nunique()>=INNER_FOLDS
            and train.later_struggle.value_counts().min()>=20 and train.later_struggle.nunique()==2
            and test.later_struggle.nunique()==2 and test.later_struggle.value_counts().min()>=20)
    if not enough:
        print('Temporal test not estimated: insufficient histories/classes under the fixed cutoff.')
        return None,audit,None
    assert train.outcome_end.max()<cutoff<=test.prediction_time.min()
    assert set(train.userId).isdisjoint(test.userId)
    p,cs,bkt_audit=fit_predict(train,test,SEED+100)
    pred=test[['userId','skill','later_struggle','prediction_time','outcome_end']].copy()
    for name,values in p.items(): pred[name]=values
    audit['selected_C']=cs
    return pred,audit,bkt_audit

9. Compare predictions and show uncertainty

For each history both models predict the same target. We resample whole students, retaining all their histories, and recompute the paired performance difference.

All gains below are oriented so positive means the expanded model is better: baseline log loss minus expanded log loss, expanded AUC/AP minus baseline AUC/AP, baseline Brier minus expanded Brier.

These are approximate percentile intervals conditional on the fitted out-of-fold predictions. They retain within-student dependence but do not refit the full pipeline in each bootstrap and do not capture all training/split or prior exploration uncertainty. We do not treat them as exact hypothesis tests. Secondary model comparisons and k=7 results are exploratory.

Show Python code
def metrics(y,p):
    return {'log_loss':log_loss(y,p,labels=[0,1]),'AUC':roc_auc_score(y,p),
            'AP':average_precision_score(y,p),'Brier':brier_score_loss(y,p)}

def performance_table(pred):
    return pd.DataFrame([{'model':name,**metrics(pred.later_struggle,pred[name])} for name in MODELS]).set_index('model')

def paired_bootstrap(pred,baseline=M2,expanded=M3,n_boot=N_BOOT):
    y=pred.later_struggle.to_numpy(); a=pred[baseline].to_numpy(); b=pred[expanded].to_numpy()
    by_student=[g.index.to_numpy() for _,g in pred.reset_index(drop=True).groupby('userId')]
    r=np.random.default_rng(SEED)
    def gains(idx):
        ma,mb=metrics(y[idx],a[idx]),metrics(y[idx],b[idx])
        return np.array([ma['log_loss']-mb['log_loss'],mb['AUC']-ma['AUC'],mb['AP']-ma['AP'],ma['Brier']-mb['Brier']])
    point=gains(np.arange(len(y))); boot=[]
    for _ in range(n_boot):
        idx=np.concatenate([by_student[i] for i in r.integers(0,len(by_student),len(by_student))])
        if np.unique(y[idx]).size<2: continue
        boot.append(gains(idx))
    if len(boot)<.95*n_boot: raise ValueError('Too many one-class student bootstrap draws.')
    low,high=np.percentile(np.array(boot),[2.5,97.5],axis=0)
    return pd.DataFrame({'metric':['log_loss','AUC','AP','Brier'],'gain':point,'95% low':low,'95% high':high,
                         'baseline':baseline,'expanded':expanded,'valid_draws':len(boot)})

def plots(pred,title):
    fig,axes=plt.subplots(1,2,figsize=(10,4))
    axes[0].plot([0,1],[0,1],'--',color='gray',label='Ideal')
    for name in [M2,M3]:
        observed,estimated=calibration_curve(pred.later_struggle,pred[name],n_bins=8,strategy='quantile')
        axes[0].plot(estimated,observed,'o-',label=name)
    axes[0].set(xlabel='Predicted struggle probability',ylabel='Observed struggle fraction',title='Calibration')
    axes[0].legend(fontsize=8)
    tab=performance_table(pred)
    axes[1].barh(tab.index,tab.log_loss,color=['#8ca3b7']*(len(tab)-2)+['#31767c']*2)
    axes[1].set(xlabel='Log loss (lower is better)',title='Same evaluation histories')
    fig.suptitle(title); fig.tight_layout()
    return fig

def interpretation(pred,delta,label):
    row=delta[delta.metric.eq('log_loss')].iloc[0]
    conclusion='The approximate interval spans zero; added predictive value is unresolved.'
    if row['95% low']>0: conclusion='The approximate interval is above zero: a positive incremental signal in this evaluation.'
    if row['95% high']<0: conclusion='The approximate interval is below zero: transitions worsened predictions in this evaluation.'
    practical=('Even the upper interval endpoint is below the illustrative practical threshold.'
               if row['95% high']<PRACTICAL_LL_GAIN else 'The interval does not rule out an improvement of the illustrative practical size.')
    return (f'**{label}:** log-loss gain = {row.gain:.5f}; approximate student-bootstrap 95% interval '
            f'[{row["95% low"]:.5f}, {row["95% high"]:.5f}]. {conclusion} {practical} '
            'This is exploratory predictive evidence, not proof of causation or proof of equivalence.')

11. Diagnose what the incremental result means

Read the ladder in order:

  1. M0 → M1: Does knowing the amount/type of help add information beyond correctness?
  2. M1 → M2: Do the specified KT summaries add information beyond counts? BKT is order-sensitive already; a small M2 → M3 improvement may mean it already captures some relevant ordering.
  3. M2 → M3: Does the transition block add information? This is the primary contrast, not the significance of an individual coefficient.
  4. M3 → shuffled: Does actual ordering look better than a single shuffled-order diagnostic? One shuffle is noisy. A result here alone cannot establish that ordering matters.
  5. Grouped → temporal: Does the conclusion persist for later students? Different populations/prevalence mean raw scores are not directly comparable; compare the within-test model increments.

If transitions improve prediction over correctness but not over state/help counts, say that help behaviour helps, with no clear additional contribution from transitions under these baselines. If the interval spans zero, the evidence is inconclusive; it is not proof of no effect. If the gain is consistently small, describe its size as well as uncertainty.

This analysis never establishes that hints cause struggle, detects gaming intent, or proves a particular intervention works. All 49 transitions together are a feature representation, not a fully observed personal network: each history contributes only two transitions at k=3 or six at k=7.

12. Reproducibility and what to report

The report should give the cohort and students, cutoff, target, feature blocks, KT fitting restrictions/fallbacks, nested grouping, primary metric, increment with approximate interval, time-test result, and the exploratory status. Report the BKT fallback/bound-hit counts; a numerically fitted model can still be weakly identified in a short window.

Before claiming an early-warning system: obtain independent data or a genuinely untouched prospective cohort, validate episode/item-affordance definitions, examine continuation/dropout selection, and agree what improvement would matter educationally. Do not retrofit a practical threshold to the observed gain.

The saved outputs describe this implementation. They are not the old starter scores and should not be mixed with RQ2's older sample. Rebuild RQ2 using the chosen common definitions if reporting the RQs as the same population.
