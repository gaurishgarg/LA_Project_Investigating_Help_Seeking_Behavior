# RQ3 complete notebook

Open **RQ3_complete_explained.html** to read the explanations and saved results in a browser. Code is collapsed and can be expanded.

Open **RQ3_complete_explained.ipynb** in Jupyter or Google Colab to change settings or rerun. The notebook explains every analytical step. The supplied Windows data path is preconfigured. In Colab, upload the Actions CSV beside the notebook. All seven source files are not required: only the Actions CSV is needed for this analysis.

The notebook needs numpy, pandas, scipy, scikit-learn and matplotlib. The completed run's exact package versions, source checksum, settings and cohort audits are in `rq3_complete_results/run_manifest.json`. Original source files are never overwritten.

Main comparison: M2 (correctness, item/skill controls, assistance/state counts, BKT/PFA summaries) versus M3 (M2 plus transitions). The three-problem window is primary. The seven-problem analysis follows RQ1's selected window and is exploratory. Timing exclusions change the RQ1 sample; see the cohort audit.

The archive includes the executed notebook, readable HTML and exported results, including anonymized student identifiers in prediction tables. It does not include the original raw data or downloaded Python dependencies.
